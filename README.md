
# 📱 Automação de Mensagens no WhatsApp com Python

Projeto desenvolvido em **Python** com o objetivo de automatizar o envio de mensagens pelo WhatsApp.

A aplicação pode ser utilizada para enviar lembretes, notificações, mensagens para clientes e automatizar tarefas repetitivas, tornando a comunicação mais rápida e prática.

---

## 🚀 Funcionalidades

- Envio automático de mensagens pelo WhatsApp
- Personalização das mensagens
- Automação de tarefas repetitivas
- Possibilidade de agendamento de mensagens
- Envio para contatos específicos
- Integração com o WhatsApp Web
- Estrutura simples e fácil de modificar

---

## 🛠️ Tecnologias utilizadas

Este projeto foi desenvolvido utilizando:

- Python
- WhatsApp Web
- Automação de navegador

Dependendo da implementação, podem ser utilizadas bibliotecas como:

- `pywhatkit`
- `pyautogui`
- `selenium`
- `time`
- `datetime`

---

## 📋 Pré-requisitos

Antes de executar o projeto, certifique-se de ter instalado:

- Python 3.8 ou superior
- Google Chrome ou outro navegador compatível
- WhatsApp ativo
- Acesso ao WhatsApp Web
- Git, caso queira clonar o repositório

Para verificar se o Python está instalado:

```bash
python --version
```

📦 Instalação

Clone este repositório:

git clone [https://github.com/seu-usuario/WhatsappProject.git](https://github.com/lucaslep/WASys.git)

Entre na pasta do projeto:

cd seu-repositorio

Crie um ambiente virtual, se desejar:

Windows
python -m venv venv

Ative o ambiente virtual:

venv\Scripts\activate
Linux / macOS
python3 -m venv venv

Ative o ambiente:

source venv/bin/activate
